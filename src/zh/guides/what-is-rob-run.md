**ROB RUN** 是 Kefir 开发的免费抢先体验（Early Access）犯罪沙盒游戏，于 2026 年 11 月 4 日在 Steam 上线。[Steam 商店页](https://store.steampowered.com/app/4262460/ROB_RUN/)把它描述为“brutal crime sandbox featuring thousands of players”（有数千名玩家的残酷犯罪沙盒）。[官网](https://robrun.com/en)则写：这是一款关于拼命往上爬的免费犯罪游戏，“只有真人玩家，以及失去一切的风险”。

Kefir 同时是开发商和发行商。商店页写明：每个警察和每个罪犯都是真人玩家，并提到“你周围有 5,000 名玩家”。玩家可以创建或加入帮派（clan），抢银行、袭击藏身处，并建造藏身处或基地。官方材料里，这座城市的名字是 **Looty Bay**。

游戏仍在公开打磨。Kefir 表示，预计抢先体验会持续大约 **6 到 12 个月**，具体取决于玩家反馈和开发进度；完整版计划增加更多地图或模式、自定义内容、成长或成就系统，并继续改进匹配、性能和网络稳定性。上线以来按日期整理的改动，见[更新与更新日志](/zh/guides/updates-and-patch-log/)。

## 价格与内购

Steam 页将其标为**免费游玩**。同一页的抢先体验说明里，Kefir 写道：游戏离开抢先体验时，不打算改价格。

帮助中心文章[付费购买会影响玩法吗？](https://kefirgames.helpshift.com/hc/en/14-rob-run/faq/1368-do-purchases-affect-gameplay/)写明：**B-Coins** 只能用于购买外观，不影响属性、平衡或游戏进度。我们核对过的帮助中心文章没有公布 B-Coins 礼包价格，因此这里也不编造价目表。

## 平台

截至本次核对，Steam 商店页列出的唯一平台是 **64 位 Windows 10 或更新系统**。配置要求部分没有列出 macOS、Linux、主机或手机。我们在 Steam 页、[robrun.com](https://robrun.com/en) 和帮助中心都没有找到官方的 PlayStation、Xbox 或移动版。若以后有变化，会先出现在这些官方页面上。

Steam 页还写明：游戏使用**内核级**的 Easy Anti-Cheat，需要同意 [ROB RUN 最终用户许可协议](https://store.steampowered.com/eula/4262460_eula_0)，并需要宽带网络。这是一款在线游戏。

<h2 id="system-requirements">配置要求</h2>

[Steam 商店页](https://store.steampowered.com/app/4262460/ROB_RUN/)和[帮助中心](https://kefirgames.helpshift.com/hc/en/14-rob-run/faq/1375-what-are-the-system-requirements/)给出的配置一致（Steam 对 CPU 和显卡名称写得更完整）。两套配置都需要 64 位 Windows 10 或更新系统、DirectX 11、网络连接，以及 20 GB 可用存储空间。

| | 最低配置 | 推荐配置 |
| --- | --- | --- |
| 处理器 | Intel Core i5-6600K 或 AMD Ryzen R5 1600 | Intel Core i5-9600K 或 AMD Ryzen 5 3600 |
| 内存 | 12 GB RAM | 16 GB RAM |
| 显卡 | NVIDIA GeForce GTX 1050 Ti、AMD Radeon RX 580 或 Intel Arc A380 | NVIDIA GeForce RTX 2070、AMD Radeon RX 5700 XT 或 Intel Arc B570 |

## 语言与更新

Steam 的语言表显示：英语和俄语提供界面、完整配音和字幕；法语、德语和西班牙（西班牙）提供界面和字幕。商店页写明一共支持六种语言，但可见表格里没有写出第六种，因此这里也不猜测。这份列表里**没有官方中文**。

Kefir 表示，游戏会[定期更新](https://kefirgames.helpshift.com/hc/en/14-rob-run/faq/1366-will-the-game-receive-updates/)，并在官方社区公布。

## 其他官方声明

Steam 页上，Kefir 披露：AI 被用于“某些图形元素的制作”。同一页还有成熟内容说明，涵盖枪支暴力、部分裸露、轻微的毒品相关提及、只用虚拟或游戏内货币的轮盘，以及抢劫、逮捕和交火等犯罪玩法。完整措辞请在[Steam 页面](https://store.steampowered.com/app/4262460/ROB_RUN/)阅读后再决定是否游玩。
