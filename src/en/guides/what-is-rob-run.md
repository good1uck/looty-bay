**ROB RUN** is a free-to-play Early Access crime sandbox by Kefir, released on Steam on November 4, 2026. The [Steam store page](https://store.steampowered.com/app/4262460/ROB_RUN/) describes it as a “brutal crime sandbox featuring thousands of players.” The [official site](https://robrun.com/en) calls it “a free-to-play crime game about clawing your way to the top. Only real players and the risk of losing everything.”

Kefir is listed as both developer and publisher. The store page says every cop and every criminal is a human player, and it mentions “5,000 players around you.” Players can form or join clans, rob banks, raid hideouts, and build a hideout or base. The city’s name, used throughout official materials, is **Looty Bay**.

The game is still being built in public. Kefir says it expects ROB RUN to stay in Early Access for about **6–12 months**, depending on player feedback and how development progresses, and that the full version is planned to add more maps or modes, customization, progression or achievements, and more work on matchmaking, performance, and network stability.

## Price and purchases

The Steam page lists the game as **free to play**. In the Early Access FAQ on that page, Kefir says: “No, we don’t plan to change the price when the game leaves Early Access.”

The Help Center article [Do purchases affect gameplay?](https://kefirgames.helpshift.com/hc/en/14-rob-run/faq/1368-do-purchases-affect-gameplay/) says **B-Coins** can only be used to purchase cosmetic items: they do not affect stats, balance, or game progression. The Help Center does not, in the articles we checked, publish a price list for B-Coin packs, so we do not invent one.

## Platforms

As of this check, the only platform listed on the Steam store page is **64-bit Windows 10 or later**. The system-requirements section does not list macOS, Linux, a console, or a mobile app. We have not found an official PlayStation, Xbox, or mobile release on the Steam page, [robrun.com](https://robrun.com/en), or the Help Center. If that changes, it will appear on those official pages first.

The Steam page also states that the game uses **kernel-level Easy Anti-Cheat**, requires agreement to the [ROB RUN EULA](https://store.steampowered.com/eula/4262460_eula_0), and needs a broadband internet connection. It is an online game.

<h2 id="system-requirements">System requirements</h2>

The [Steam store page](https://store.steampowered.com/app/4262460/ROB_RUN/) and the [Help Center](https://kefirgames.helpshift.com/hc/en/14-rob-run/faq/1375-what-are-the-system-requirements/) agree on the following (Steam’s wording is slightly more complete on processor and GPU names). Both configurations need 64-bit Windows 10 or later, DirectX 11, a network connection, and 20 GB of available storage.

| | Minimum | Recommended |
| --- | --- | --- |
| Processor | Intel Core i5-6600K or AMD Ryzen R5 1600 | Intel Core i5-9600K or AMD Ryzen 5 3600 |
| Memory | 12 GB RAM | 16 GB RAM |
| Graphics | NVIDIA GeForce GTX 1050 Ti, AMD Radeon RX 580, or Intel Arc A380 | NVIDIA GeForce RTX 2070, AMD Radeon RX 5700 XT, or Intel Arc B570 |

## Languages and updates

The Steam language table shows English and Russian with interface, full audio, and subtitles, and French, German, and Spanish (Spain) with interface and subtitles. The store page says the game has six supported languages in total; it does not name the sixth language in the visible table, so we do not guess it here. There is **no official Chinese localization** on that list.

Kefir says the game will receive [regular updates](https://kefirgames.helpshift.com/hc/en/14-rob-run/faq/1366-will-the-game-receive-updates/), announced in official communities.

## Other official disclosures

On the Steam page, Kefir discloses that AI is used “in the creation of certain graphic elements.” The same page includes a mature-content description covering firearm violence, partial nudity, mild references to drug-related substances, in-game roulette that uses virtual or in-game currency only, and criminal gameplay such as robbery, arrest, and shootouts. Read the full wording on [Steam](https://store.steampowered.com/app/4262460/ROB_RUN/) before you play.
